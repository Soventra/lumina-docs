Microsoft 365 Copilot cover

Static Lumina × Microsoft 365 Copilot logo pairing on a subtle dot grid, with no headline and a transparent background. Desktop: 1600x836, horizontal layout. Mobile: 800x700, stacked layout. Light and dark PNG/SVG variants use matching geometry and preserve the original logos. The React component selects the page theme and mobile layout; it contains no animation.

Reproduce all variants with:
  node render.mjs
Install sharp in the local project, or set SHARP_PATH to its installed package directory. The script uses the fonts under assets/. Generated review files are ignored by Git.

scene.mjs is the editable source. Each exported SVG embeds its logo assets so it can be opened or shared on its own. PNGs preserve transparency.
